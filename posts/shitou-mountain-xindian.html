三進三出新店獅頭山

本路線由三進三出七星山所啟發。

For English readers: XINDIAN LION'S HEAD MOUNTAIN HIKING TRAIL (新店獅頭山登山步道)

獅頭山（小獅山）雖然離新店市區很近，但從來沒有爬過。最近為了找能負重常訓的路線，把眼光重新拉回來。除了平路之外，饒富台灣山林郊山特速的路線也要尋覓。新店獅頭山頗適合各種組合路線，以下為由說明。

相較於七星山，獅頭山的海拔爬升在短距離並不遜色。山勢有展望且有雙峰。步道建立的年代不同，鋪面不同，變化頗多。攀爬的人相對來說比較少，對不喜人擠的朋友們是個福音。全程有樹蔭路線高達80%以上，夏天中午也能攀爬。比較特別的是有命名的涼亭高達11個。全區路徑精小鍛鍊，雖然不太能跑的起來，但卻適合在「戰術體能」框架下追求時間和速度的朋友們嘗試。

整體條件合理，適合常訓。

此路線我一向負重，最低4公斤直到16公斤。我此次採取的「三進三出加兩繞」的路線約4.4公里，累積爬升超500米。緩走無跑：

<一進> 中興路登山口（公車站牌：舊郵政館） => 中山亭 => 

<一繞> 繞往玉山亭 => 

<二繞> 繞回天籟亭 => 梅花獅子亭 => 青年亭 => 慈暉亭 => 

<一出/二進> 春路登山口 => 繞回慈暉亭 => 

<二出> 下文中路登山口 => 

<三進> 進能仁家商登山口 => 青年亭 =>  獅子祿亭 => 中山亭 => 

<三出> 中興路登山口

中間涼亭數量龐大，很容易叉繞不同短程路線。但我覺得不要緊，此山頭如座鞍孤立，兩小峰繞來繞去，不太會走到其他域外路線。

路線不好跑，木棧板維護狀況大致沒有問題。當然不能跟國家公園內的大屯山系比，但離捷運如此近，交通省下的時間是一大優勢。

夜間：可能不適合，我還沒有夜間走過。

其他：慈暉亭東北側另有一條路徑下檳榔路，若取之，可完整畫出四進四出。
