壯年田徑各分齡表現的比較算法 (Age-Grading)

本篇是因應2025年世壯運 (World Masters Games) 在台灣舉辦所發想的文章，主要是針對田徑運動 (masters athletics) 的參賽者。

Age Grading（編按：中文不知道如何翻譯比較精確）

在田徑運動中，Masters Athletics（即長青/壯年田徑）的分齡表現的算法主要使用的是 Age-Grading 系統。我們都知道人到了一個年紀要去比田徑運動是很不簡單的，大家總會想說我當年跑幾秒又幾秒，現在幾歲只剩下幾秒了。到底年齡增長後水平如何？這問題想必很多人都會有。不過 masters athletics 在台灣畢竟還是屬於體育班年代的「產物」，意即會參加而且有好表現的者，多半有相當的體育系統背景。這在統計的樣本會有偏差也會有不足的現象。

世壯運的成績雖然沒有認證，但參賽者還是可以根據自身年齡，透過 age-grading 系統的估算，來比較不同分齡之間的運動表現。

Age-Grading 系統

目的：這個系統在於讓不同年齡組的運動員能夠比較他們的表現。通過 Age-Grading，可以將一個年長運動員的成績轉換為一個假設的「公開賽」或是「青年賽」的年齡組成績，使得不同年齡層的運動員可以比較他們的相對表現。

計算方法

Age-Factors 和 Age-Standards：每個年齡組和每個項目（如短跑、跳遠、投擲等）都有特定的 Age-Factor 和 Age-Standard。Age-Factor 是一個用於調整壯年運動員成績的係數，而 Age-Standard 是該年齡組的「世界最佳」或「標準」成績。

成績調整：一個運動員的實際成績會乘以相應的 Age-Factor 來計算出等同於公開年齡組的成績。例如，如果一個60歲的男性在100米短跑中跑了13秒，而該年齡組的 Age-Factor 是0.85，那麼他的 Age-Graded 成績會是13秒乘以0.85，得到11.05秒。

Age-Graded 百分比：這是一種標準化的百分比，用於比較不同年齡和性別的運動員。這個百分比反應了運動員的成績相對於該年齡組的標準成績的比例。計算公式通常是：

  • 對於跑步和步行：Age-Graded % = (Age-Standard / Actual Performance) × 100
  • 對於跳躍和投擲：Age-Graded % = (Actual Performance / Age-Standard) × 100

這些方法和概念由 World Masters Athletics（WMA）管理，Age-Grading 表格經過多年來的更新以反應運動表現隨著年齡增長的變化。

Age-Grading 計算示範

讓我們來看一個簡單的 Age-Grading 示範，假設我們要為一位50歲的男性跑者計算他在100米短跑中的 Age-Graded 成績：

  1. 實際成績：假設這個跑者跑了100米用了14秒。
  2. Age-Standard：
    • 根據 WMA（或任何其他 Age-Grading 表）的數據，50歲男性的100米跑 Age-Standard 可能是11.6秒（這是一個假設的數值，實際數值會依據最新的表格而變化）。
  3. Age-Factor：
    • 假設50歲男性的 Age-Factor 為0.88（這也是假設的數值）。
  4. 計算Age-Graded成績：
    • 首先，我們將實際成績乘以 Age-Factor 來得到等同於開放年齡組的成績：
      • Age-Graded Performance = 實際成績 × Age-Factor
      • = 14秒 × 0.88
      • = 12.32秒
  5. 計算Age-Graded百分比：
    • 然後，我們使用 Age-Standard 來計算這個成績相對於該年齡組標準成績的百分比：
      • Age-Graded % = (Age-Standard / Actual Performance) × 100
      • = (11.6秒 / 14秒) × 100
      • = 82.86%

上述例子展示了如何將一個50歲男性的100米成績調整為一個 Age-Graded 百分比，這樣他就能與其他年齡組的運動員進行比較。這個百分比表明他的跑步速度相對於50歲男性的標準成績而言有多好。

請注意，實際的 Age-Factor 和 Age-Standard 會根據最新的 WMA 表格或其他 Age-Grading 數據來調整，所以這裡的數字是假設性的，實際計算時應該查詢最新的官方表格數據。
